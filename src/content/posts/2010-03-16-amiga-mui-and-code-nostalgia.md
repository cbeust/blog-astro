![The MUI toolkit for the Amiga](http://www.sasg.com/mui/preview.gif)

A session of link hopping caused me to hunt down a program I wrote for the Amiga in 1994. I didn't really think I would be able to locate it, but once again, I underestimated the power of the Internet. 

Not only did I find it but [Aminet, the entire archive where I published it, is actually online!](http://aminet.net/). The software is an accounting program called [Banker](http://aminet.net/package/biz/misc/Banker-0.99a) which featured a fairly complex user interface. I was actually using a GUI toolkit called [MUI (Magic User Interface)](http://www.sasg.com/mui/) which was extremely impressive for its time. It featured complex widgets with support for a lot of listeners, on the fly reloading of resources and skins, localization, etc... 

The only problem with MUI is that it was a bit ahead of its time processor-wise, so user interfaces written with it tended to be a bit sluggish. But it was totally worth it. 

Back to Banker, I realized while browsing its entry on Aminet that the archive contained its source, so I suddenly became very eager to see the kind of code that I was writing sixteen years ago. The archive is a `.lha`, another format that was popular on the Amiga, and for which I was quickly able to find a decompressor running on Mac called [DropUnLha](http://mac.softpedia.com/get/Compression-Tools/DropUnLHa.shtml). 

I was bracing myself, expecting the worst, but... well, it's actually not that bad. I uploaded the whole project to [github.com](http://github.com/cbeust/banker-amiga) for posterity, and here is [one of the sources](http://github.com/cbeust/banker-amiga/blob/master/src/common.c). Check out this cute comment ASCII art at the top of the file, neat, uh? 

![](https://raw.githubusercontent.com/cbeust/beust-com/master/pics/ascii-art.png)

My only regret is that I wasn't able to come up with any screen shot of Banker, even in [this review of my program from a Dutch magazine](http://amr.abime.net/review_24955), so I would need to run the [the Amiga emulator](http://www.amigaemulator.org/) to really see what it looked like.
