A few weeks ago, I embarked on my latest project: writing a PC-XT emulator (8086). I had wanted to do this for a very long time because I felt that my knowledge of Intel CPUs was lacking, so I decided to dive in. It’s been a fun journey so far, starting by getting my CPU to pass all the tests, and then tackling the emulator itself. I’m including a few screenshots of the progress so far, from just showing the very beginning of the boot process, emulating the BIOS, then using a real BIOS, then implementing disk drives, then CGA. A lot more to work on, but it’s been very exciting so far, and as much I dislike the 8086 assembly, there are a lot of very interesting things in this architecture designed more than forty years ago, and which powers our civilization today...
