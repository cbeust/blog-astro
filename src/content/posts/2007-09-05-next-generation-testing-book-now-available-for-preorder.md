Our book is now [available for preorder on Amazon](http://www.amazon.com/Next-Generation-Java-Testing-Advanced/dp/0321503104/ref=sr_11_1/103-5091514-2603034?ie=UTF8&qid=1188921106&sr=11-1"). The working title is "Next Generation Java Testing". 

It's approximately five hundred pages of dense Java-related testing information illustrated by a lot of (mostly small) listings and code snippets. [The Rough Cut version is also available on Safari](http://safari.informit.com/9780321503107). 

It should be publicly available in November.
