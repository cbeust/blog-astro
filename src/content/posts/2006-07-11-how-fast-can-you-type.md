    It is only the first shot that counts, because the text doesn''t change - you can just learn and practice the text! So of course your subsequent shots are going to get faster...

    You can get faster if you have the correct finger positions (obviously), but also if you hit the keys lightly. It''s easier to go faster on a laptop, because of the lower action required. This is analogous the action required for guitar - fast shred guitarists use low fret action, because it allows them to sweep pick to perform other speed techniques easier.'
